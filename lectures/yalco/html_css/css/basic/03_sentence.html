정렬과 간격

text-align 속성은 텍스트의 정렬 방식을 지정합니다. 직관적으로 알 수 있듯 left는 왼쪽, center는 가운데, right는 오른쪽으로 텍스트(및 인라인 요소들)를 정렬한다. justify는 왼쪽으로 정렬하면서 텍스트가 여러 줄이 될 때 마지막 줄을 제외한 줄들의 오른쪽이 나란히 되도록 각 줄의 공간을 조절한다.


letter-spacing으로는 자간, word-spacing으로는 단어 간격, line-height로는 줄 높이를 조절할 수 있다.
