텍스트를 한 줄로 표시하는 태그

1. <b>태그와 <strong>태그는 텍스트를 굵게 표시한다. 다만 <b>태그는 단순히 굵게, <strong>태그는 강조할 텍스트를 굵게 표시한다.

2. <i>태그와 <em>태그는 텍스트를 기울여 표시한다. 다만 <i>태그는 단순히 기울여, <em>태그는 강조할 텍스트를 기울여 표시한다.

3. <mark>태그는 텍스트에 형광펜 표시를 한다.

4. <small>태그는 텍스트를 작게 표시한다.
